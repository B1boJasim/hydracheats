# HYDRA CHEATS --- Support

Use the official HydraCheats channels for product questions, purchasing,
licensing, and technical support.

## Official Contact

-   **Website:** https://hydracheats.com
-   **Email:** support@hydracheats.com
-   **Discord:** https://discord.gg/UR6psFPfK9

## Before Contacting Support

For a normal technical problem, it can help to include:

-   Product name (`SPOOFER`, `HydraCheats.exe`, or `HydraCheats.lua`)
-   HydraCheats version, if known
-   Windows version
-   Relevant error message
-   A short description of what happened

> \[!CAUTION\] Never publish license keys, passwords, account
> credentials, payment information, or other secrets in a public GitHub
> issue.

## Purchasing

The current official FAQ directs customers to purchase by contacting
HydraCheats through Discord.

## Feature Requests

Feature suggestions can be submitted through the official HydraCheats
community/support channels.
