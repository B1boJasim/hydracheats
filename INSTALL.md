# HYDRA CHEATS --- Installation

## Requirements

Before installation, verify the current product requirements.

### HydraCheats.exe

-   Windows 10 (64-bit) or Windows 11 (64-bit)
-   FiveM
-   Valid HydraCheats license

### HydraCheats.lua

-   Windows 10 (64-bit) or Windows 11 (64-bit)
-   FiveM
-   Valid HydraCheats license
-   Compatible Lua executor

## Purchase

According to the current official FAQ, purchases are handled by
contacting HydraCheats through the official Discord.

-   Website: https://hydracheats.com

## Installation

Installation details can change between releases. Follow the
instructions distributed with the current product version or
instructions provided through official HydraCheats support.

Do not rely on old installation instructions from mirrors or unofficial
downloads.
